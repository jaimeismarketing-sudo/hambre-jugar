Tu carrera, en tu navegador.

Esta edición web funciona sin tener encendido el servidor del PC. Abre el enlace del juego en Safari para jugar. Necesitas conexión para cargar el sitio.

Abrir HAMBRE

Las partidas se guardan en este navegador.

La edición web no sincroniza automáticamente con Windows, con el servidor móvil anterior ni con otros dispositivos. Conserva una exportación antes de cambiar de navegador, dirección o dispositivo, y antes de borrar datos de Safari.

Empezar en Normal o God Mode

Al crear una carrera nueva puedes elegir Normal o God Mode. God Mode permite fijar el capital inicial entre $0 y $30.000.000 y empezar con fama 100/100. No añade fans, habilidades ni reputación: esos valores mantienen su punto de partida.

Estas ventajas se asignan una sola vez, al crear la carrera. Después, la fama y la economía siguen las reglas del juego. Las carreras existentes conservan sus cifras, incluso si se crearon antes en God Mode; recargar o importar no vuelve a asignar fama 100.

Traer tu carrera actual

  1. En la instalación o enlace donde está tu carrera, abre Mis partidas.
  2. Elige Exportar esta carrera o Exportar todas. Conserva ese archivo JSON original.
  3. En el iPhone, guarda el archivo en Archivos, por ejemplo mediante iCloud Drive o AirDrop.
  4. Abre esta edición web en Safari, entra a Mis partidas → Importar partida y selecciona el JSON.
  5. Comprueba nombre, semana y caja antes de continuar. La importación añade carreras separadas; no elimina las que ya existen.

Guardar una copia y regresar a Windows

En Mis partidas, usa Exportar esta carrera o Exportar todas. Safari permite guardar la descarga en Archivos; si muestra una vista del archivo, usa Compartir para guardarlo. Después abre Windows y usa Importar partida. Conserva ambas copias hasta comprobar la semana, el dinero y los contratos.

La importación admite hasta 64 MiB por archivo y hasta 1.000 carreras. Estos límites no garantizan que todo quepa en el almacenamiento disponible del navegador. Para carreras grandes, exporta e importa una por una.

Si aparece un aviso de guardado

Pausa y exporta la carrera antes de cerrar Safari. Un aviso de falta de espacio, permisos o conflicto significa que los cambios pueden seguir solo en memoria. Evita jugar la misma edición en varias pestañas a la vez. El modo privado y borrar los datos del sitio pueden impedir conservar tus carreras.

Tiempo y controles en iPhone

La carrera abre pausada. Elige Reproducir cuando estés listo: x1 equivale a un día cada 60 segundos; x3, a un día cada 20 segundos; x10, a un día cada 6 segundos. Las velocidades rápidas están identificadas por separado.

Al cerrar el juego no se simula tiempo retroactivo. Safari puede suspender una pestaña cuando queda en segundo plano: vuelve al juego para continuar. Puedes usar Safari → Compartir → Añadir a pantalla de inicio; conserva una exportación si cambias cómo lo abres.

Después de una actualización

Usa siempre la misma dirección para continuar con el guardado de esa edición. Si cambia el dominio, importa tu copia. Si aparece una pantalla vacía, recarga sin borrar los datos del sitio; exporta antes de cualquier limpieza.
